- Einstellungen: Die Auswahl springt nicht mehr. Die linke Liste landet auf dem offenen Bereich, Knopfreihen starten links, und nach Dialogen, Unterseiten oder dem Entfernen bleibt der Fokus an seiner Stelle; die Scrollposition wird gemerkt.
- Automationen: jede Aktion als ganze Zeile, OK öffnet ein Menü (Farbe & Helligkeit, Entfernen).
- Neu: **Lichtfarbe je App** – 12 Farben und Weißtöne plus Helligkeit, z. B. YouTube → Wohnzimmer blau, 25 %. Beim Hinzufügen eines Lichts auch „Mit Farbe einschalten“.
- Home-Taste und App-Symbol führen immer zur Startseite statt zurück in die Einstellungen.
- Code-Review: kleinere Fehler behoben und alter, ungenutzter Code entfernt.
